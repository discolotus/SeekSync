# Third-party software

## Sockseek

SeekSync can download and install the official Sockseek command-line executable as a separate tool at first launch. Sockseek is not incorporated into the SeekSync executable.

- Project: https://github.com/fiso64/sockseek
- Pinned release: https://github.com/fiso64/sockseek/releases/tag/v3.0.4
- Corresponding source: https://github.com/fiso64/sockseek/tree/v3.0.4

- License text: https://github.com/fiso64/sockseek/blob/v3.0.4/LICENSE

The official release archive is downloaded directly from GitHub and verified against the SHA-256 digest published in GitHub's release metadata.
